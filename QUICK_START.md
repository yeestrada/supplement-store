# 🚀 Quick Start - Supplement Store

## Installation and Execution (2 minutes)

### 1. Install dependencies
```bash
npm install
```

### 2. Run development server
```bash
npm run dev
```

### 3. Open in browser
```
http://localhost:3000
```

## ✅ Quick Verification

### Storefront
- [ ] Homepage: `http://localhost:3000`
- [ ] Products: `http://localhost:3000/products`
- [ ] Product details: `http://localhost:3000/products/1`
